# Lesson 19 — Robustness Benchmarking and Red-Teaming Toolkits

Objectives:

- Explain what AutoAttack is and why it uses four complementary attacks.
- Use IBM ART to run a multi-attack robustness audit.
- Situate a model on the RobustBench leaderboard by its AutoAttack accuracy.
- Describe the six phases of a structured red-teaming workflow.
- Configure a continuous monitoring integration that flags robustness regression.

## Main Concepts

- Standardized evaluation protocols: RobustBench leaderboard, AutoAttack benchmark
- Adversarial Robustness Toolbox (ART): attack, defense, and evaluation API
- Automated vulnerability auditing: multi-attack ensemble evaluation
- Red-teaming process: structured adversarial evaluation workflow for production models

## Learning Outcomes

- Student can explain what AutoAttack is and why it is preferred over single-attack evaluation for leaderboard comparisons.
- Student can use IBM ART to run a multi-attack robustness audit and produce a structured vulnerability report.
- Student can situate a model on the RobustBench leaderboard by its AutoAttack accuracy.
