# Lesson 24 — Privacy Risks and Data Leakage in Machine Learning

Objectives:

- Define memorization and distinguish it from generalization.
- Apply prefix-prompting extraction tests to a fine-tuned generative model.
- Explain gradient leakage and output confidence as privacy side channels.
- State GDPR Article 17 and CCPA obligations triggered by a memorization finding.

## Main Concepts

- Training data memorization: definition, measurement, and unintended verbatim extraction
- Side-channel leakage: gradient leakage and output confidence as privacy side channels
- Regulatory context: GDPR right to erasure, CCPA personal information, AI Act compliance obligations
- Memorization quantification: exposure metric and extraction likelihood

## Learning Outcomes

- Student can define and distinguish memorization, unintentional extraction, and side-channel leakage.
- Student can apply prefix-prompting extraction tests to a generative model and quantify memorization using the exposure metric.
- Student can state the GDPR and CCPA obligations triggered by detected memorization and map them to technical mitigations.
