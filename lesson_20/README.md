# Lesson 20 — Model Inversion and Reconstruction Attacks

Objectives:

- Describe model inversion and reconstruction attack techniques.
- Explain defenses and measurable mitigation strategies.

## Main Concepts

- Model inversion and reconstruction attack techniques.
- Membership and attribute inference as privacy threats (context for inversion)
- Evaluation metrics for reconstruction fidelity and privacy leakage

## Learning Outcomes

- Student can describe model inversion and reconstruction attack techniques.
- Student can explain defenses and measurable mitigation strategies.
