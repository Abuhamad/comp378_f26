# Lesson 06 — AI Development Lifecycle and MLOps

Objectives:

- Articulate every stage of the ML development lifecycle.
- Instrument a training script with MLflow to log parameters, metrics, and artifacts.
- Version a dataset and model checkpoint with DVC, then reproduce a prior training run.
- Describe deployment patterns given latency and scale requirement.

## Main Concepts

- End-to-end ML pipeline stages: data ingestion, feature engineering, training, validation, deployment
- Model versioning and experiment tracking: MLflow, DVC
- CI/CD for ML: automated retraining, model registry, staged rollout
- Deployment patterns: batch inference, real-time APIs, edge deployment

## Learning Outcomes

- Student can articulate every stage of the ML development lifecycle and name a tool or practice at each stage.
- Student can set up MLflow tracking, log parameters, metrics, and artifacts across multiple training runs, and compare runs in the UI.
- Student can version a dataset and model checkpoint with DVC and reproduce a prior run from a git commit.
