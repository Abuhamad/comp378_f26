# Lesson 02 — Evolution and Architectures of AI

Objectives:

- Describe the McCulloch-Pitts neuron.
- Explain the perceptron convergence theorem.
- Distinguish gradient descent from perceptron updates.
- Describe AlexNet’s architectural innovations.
- Explain ResNet’s residual skip connection.
- Describe the Transformer attention mechanism.

## Main Concepts

- Rule-based expert systems and their limitations
- Statistical learning era: decision trees, support vector machines (SVMs)
- Shallow vs. deep neural networks: structural differences and capability gaps
- Empirical comparison methodology: same dataset, multiple model families

## Learning Outcomes

- Student can describe how each generation of AI systems addressed the limitations of the previous one.
- Student can implement a decision tree, SVM, and MLP using scikit-learn on the same dataset.
- Student can compare model families by accuracy, training time, and interpretability on a tabular benchmark.
