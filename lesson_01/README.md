# Lesson 01 — Introduction to Artificial Intelligence and Modern Paradigms

Objectives:

- Distinguish rule-based AI from machine learning by data dependency.
- Explain supervised learning using labeled examples, loss minimization, and generalization.
- Distinguish unsupervised from supervised learning and name one clustering algorithm.
- Contrast discriminative models with generative models.
- Explain the shift from hand-engineered features to learned deep representations.

## Main Concepts

- History of AI: symbolic AI, connectionist AI, statistical learning eras
- Paradigm comparison: symbolic vs. sub-symbolic vs. modern foundation-model approaches
- Trustworthiness taxonomy: security, privacy, fairness, governance as orthogonal pillars
- Toolchain orientation: PyTorch, scikit-learn, Hugging Face `transformers`, IBM ART

## Learning Outcomes

- Student can place a given AI technique within its historical era and paradigm.
- Student can map the four trustworthiness pillars to concrete course sections.
- Student can configure and verify the course toolchain and run a baseline tabular classifier end-to-end.
