# Lesson 04 — Advanced Deep Architectures

Objectives:

- Derive 2D convolution output dimensions from kernel size, stride, and padding.
- Trace forward and backward passes through a simple ConvNet.
- Explain residual connections and their gradient flow advantage.
- Describe the attention mechanism and how query-key dot products weight values.
- Describe self-attention and its quadratic computational cost.

## Main Concepts

- Convolutional neural networks: convolution, pooling, receptive fields, feature maps
- Recurrent architectures: vanishing gradient problem, LSTMs, GRUs
- Attention mechanism: scaled dot-product attention, multi-head attention
- Transformer architecture: encoder-decoder structure, positional encoding, self-attention

## Learning Outcomes

- Student can explain why convolution is parameter-efficient for spatial data and extract intermediate feature maps.
- Student can distinguish attention from recurrence and state where Transformers outperform RNNs.
- Student can fine-tune a pre-trained ResNet on CIFAR-10 and visualize activation maps from intermediate layers.
