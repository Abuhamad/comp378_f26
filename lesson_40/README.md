# Lesson 40 — Final: AI Red-Teaming and Blue-Teaming

Objectives:

- Produce a structured red-team plan document.
- Execute a structured red-team assessment covering at least three attack classes.
- Map each discovered attack to its kill chain stage.
- Activate blue-team monitoring to detect at least two attacks in progress.
- Produce a complete AI incident response report for a detected attack.
- Compile a combined red-team report integrating all findings.

## Main Concepts

- End-to-end security posture synthesis: integrating defenses across the full AI lifecycle
- Red-teaming methodology: structured adversarial evaluation, kill chain mapping
- Continuous telemetry and monitoring: runtime anomaly detection, model drift alerting
- AI incident response: detection, containment, remediation, post-mortem
- Multi-domain CTF: combining data poisoning, evasion, model extraction, and LLM injection in a unified challenge

## Learning Outcomes

- Student can execute a structured red-team assessment against a deployed AI application covering at least three attack classes.
- Student can map a discovered attack to its kill chain stage and propose a defense-in-depth countermeasure.
- Student can produce an AI incident response report including detection timeline, containment actions, and remediation plan.
