# Lesson 07 — Threat Modeling for AI Systems

Objectives:

- Classify any AI attack by attacker goal, capability, and knowledge level.
- Enumerate the four main AI attack surfaces.
- Produce a formal STRIDE threat model document for a given AI system.
- Map a deployment scenario to the appropriate NIST AI RMF risk tier.

## Main Concepts

- Adversarial ML taxonomy: attacker goals (integrity, availability, confidentiality) and capabilities (training-time vs. inference-time)
- Attacker knowledge axis: white-box, grey-box, black-box
- AI-specific attack surfaces: data pipeline, model weights, inference API, deployment infrastructure
- Threat modeling methodology: STRIDE applied to AI; NIST AI RMF threat categories

## Learning Outcomes

- Student can classify any described AI attack by attacker goal, capability, and knowledge level.
- Student can enumerate attack surfaces in a given AI pipeline and map each to a STRIDE threat category.
- Student can produce a formal STRIDE threat model document for an AI system with mitigations for each identified threat.
