# Lesson 03 — Deep Learning Fundamentals

Objectives:

- Trace forward and backward passes through a two-hidden-layer network by hand.
- Implement a two-layer ReLU network in NumPy.
- Explain the vanishing gradient problem.
- Describe Xavier and He initialization.
- Code a custom PyTorch dataset and dataloader.
- Implement early stopping and interpret validation curves.

## Main Concepts

- Neural network architecture: layers, activations, weight initialization
- Forward propagation: computation graph and tensor operations
- Loss functions: cross-entropy, mean squared error, and their gradients
- Backpropagation: chain rule derivation and gradient flow
- Gradient descent optimizers: SGD, momentum, Adam

## Learning Outcomes

- Student can trace forward and backward passes through a multi-layer network by hand.
- Student can implement a multi-layer perceptron from scratch in PyTorch without using high-level layer APIs.
- Student can train the from-scratch MLP to >97% accuracy on MNIST and explain each hyperparameter choice.
